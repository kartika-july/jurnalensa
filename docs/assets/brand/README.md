Scene/backdrop: Actual transparent background with preserved alpha, no white or colored backdrop.
Constraints: Exactly one open book and exactly one five-point star. No text or letters. No mockup. No shadows, gradients, textures, decorative sparkles, extra symbols or watermark. Clean solid fills with crisp edges and clear transparent negative space.
